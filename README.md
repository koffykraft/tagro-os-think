# TAGRO OS Think

TAGRO OS Think is the versioned thinking repository for TAGRO OS.

It exists to hold ideas before they become software, policy, workflow, doctrine, or operating rules.

## Purpose

- preserve owner ideas without dilution
- preserve AI proposals without silently turning them into TAGRO doctrine
- develop shared concepts through explicit versions
- provide a durable reference for future builds
- use Git history to show how an idea changed, when, and why

## Core rule

**Thinking is not implementation.**

An idea may be useful, incomplete, contradictory, provisional, rejected, superseded, or later accepted. This repository records that evolution.

## Provenance classes

Every substantive note should identify its source:

- **OWNER** — stated or explicitly approved by the owner
- **AI** — generated or proposed by an AI system
- **SHARED** — developed through interaction and explicitly retained as a joint working concept
- **REFERENCE** — external technical or factual material

AI material must never be presented as owner doctrine unless explicitly approved.

## Status classes

Suggested statuses:

`SEED → WORKING → REVIEW → ACCEPTED → SUPERSEDED → RETIRED`

Accepted does not mean immutable. TAGRO OS assumes flux.

## Repository map

- `docs/primers/` — compact governing primers and white papers
- `docs/concepts/` — major conceptual building blocks
- `ideas/owner/` — owner-originated ideas
- `ideas/ai/` — AI-originated proposals
- `ideas/shared/` — jointly developed working concepts
- `decisions/` — explicit decisions and their reasoning
- `templates/` — templates for new ideas and decisions
- `archive/` — material intentionally removed from active thought but retained historically

## Versioning

Documents that express evolving thought carry a semantic working version such as `v0.1`, `v0.2`, `v1.0`.

Git history remains the canonical change record. Do not overwrite history merely to make an idea appear cleaner in retrospect.

## Governing proposition

> Preserve what is known. Keep what may change revisable. Propagate consequences, not assumptions. Never confuse the current answer with permanent truth.
